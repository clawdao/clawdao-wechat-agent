# 公众号封面图设计标准

> 核心原则：**一图二用**。每张封面图必须既能作为"原始大图"使用，又能从中心裁剪出 1:1 分享图，且**核心内容不缺失**（核心文字仍然完整）。

---

## 一、用途分类

### 1. 头图横幅 `900×383`
- **唯一用途**：公众号订阅号顶部固定位置
- **裁剪要求**：不强制支持 1:1 裁剪（比例差太大，1:1 裁剪会丢失约 57% 宽度）
- **设计要求**：核心元素横向居中对齐，整体布局紧凑

### 2. 文章封面 `900×500`
- **用途 ①（主图）**：公众号推送正文大图
- **用途 ②（1:1 分享图）**：朋友圈 / 微信群 / 个人号分享缩略图
- **裁剪要求**：**必须**支持从中心裁剪出 `500×500`，所有核心内容不能被裁掉

### 3. 1:1 分享图 `500×500`
- **来源**：从 `文章封面 (900×500)` 居中裁剪 500×500 得到
- **裁剪掉的区域**：左右两侧各 200 像素（"延展区"）
- **后续可放大**：根据需要可上采样到 `1080×1080`（朋友圈高清分享）

---

## 二、中心安全区原则（核心规则）

### 2.1 安全区定义

> **文章封面（900×500）的中心安全区 = 中央 500×500 矩形**
> - 横向范围：`200 ~ 700` 像素
> - 纵向范围：`0 ~ 500` 像素（即全高）

> **头图横幅（900×383）的中心安全区 = 中央 500×383 矩形**
> - 横向范围：`200 ~ 700` 像素
> - 纵向范围：`0 ~ 383` 像素

### 2.2 元素三层分类

| 层级 | 包含内容 | 位置要求 | 1:1 裁剪后保留？ |
|------|----------|----------|------------------|
| **核心层** | LOGO、主标题、副标题、CTA / 引导语 | **必须落在中心 500×500 安全区内** | ✅ 完整保留 |
| **次要信息层** | 产品矩阵列表、日期、作者、副标识、装饰文案 | 可放在延展区（两侧 200 像素） | ❌ 可丢失 |
| **装饰层** | 光晕、网格、纹理、点缀元素、渐变背景 | 任意位置 | 部分或全部丢失 |

### 2.3 延展区定义

- **文章封面延展区**：横向 `0~200` 和 `700~900`，共 400 像素宽
- **头图横幅延展区**：横向 `0~200` 和 `700~900`，共 400 像素宽
- **延展区用途**：放次要信息、装饰元素、长产品矩阵；**绝不放置核心标题、CTA**

> ⚠️ **核心规则：核心文字一旦被裁剪丢失，整张封面图就失败。**

## 三、布局规则（文章封面 900×500）

```
┌──────────────────────────────────────────────────────────────┐
│ ┌─────────────── 中心安全区 500×500 ───────────────┐         │
│ │                                                  │         │
│ │                  [LOGO 居中]                     │  延展  │
│ │                                                  │         │
│ │            ClawDao 重塑企业（主标题）             │         │
│ │                                                  │         │
│ │       AI · 区块链 · 觉知岛 · 一站式企业认知升级   │         │
│ │                                                  │         │
│ │           [扫码关注 AI 深度学堂]                  │         │
│ │                                                  │         │
│ └──────────────────────────────────────────────────┘         │
│  延展  觉知岛 SaaS · Clawdao 龙虾岛 · DDN 区块链 · Codex 训练营  │
│  区                                                          │
└──────────────────────────────────────────────────────────────┘
   200px                                          200px
```

### 3.1 各元素位置规则

| 元素 | 横向 | 纵向 | 是否核心 |
|------|------|------|---------|
| LOGO | 中心安全区内顶部居中（约 x=400±40） | 距顶 40-60 像素 | ✅ 核心 |
| 主标题 | 中心安全区内居中 | 距顶 130-180 像素 | ✅ 核心 |
| 副标题 | 中心安全区内居中 | 主标题下方 30-40 像素 | ✅ 核心 |
| CTA | 中心安全区内底部居中 | 距底 60-90 像素 | ✅ 核心 |
| 产品矩阵 | 居中（可横跨延展区） | 距底 25-45 像素 | ⚪ 次要 |
| 装饰元素 | 任意 | 任意 | ⚪ 装饰 |

### 3.2 头图横幅（900×383）布局规则

- 核心元素（LOGO、主标题、副标题、CTA）**全部居中对齐**
- 产品矩阵可放在延展区底部
- 因为高度有限（383），纵向布局紧凑
- 不强制支持 1:1 裁剪

## 四、命名规范

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 头图横幅 | `{公众号名}_头图横幅_{宽}x{高}.png` | `AI深度学堂_头图横幅_900x383.png` |
| 文章封面 | `{公众号名}_文章封面_{宽}x{高}.png` | `AI深度学堂_文章封面_900x500.png` |
| 1:1 分享图 | `{公众号名}_分享小图_500x500.png` | `AI深度学堂_分享小图_500x500.png` |

---

## 五、公众号正文规则

> ⚠️ **公众号正文不放封面图**
>
> 封面图（文章封面 + 1:1 分享图）仅用于：
> - 文章顶部首图（公众号编辑器里手动插入）
> - 朋友圈 / 社群分享缩略图（1:1 居中裁剪）
>
> 正文中使用单独的内容配图（用 `seedream_generator.py` 等工具按需生成）。

---

## 六、生成与裁剪

- **主图生成**：`python3 aideep_cover.py` 同时输出头图横幅 + 文章封面
- **1:1 裁剪**：用 ImageMagick 或 Pillow 从文章封面居中裁剪
  ```python
  from PIL import Image
  cover = Image.open("AI深度学堂_文章封面_900x500.png")
  # 中心 500×500 区域：左 200, 上 0, 右 700, 下 500
  square = cover.crop((200, 0, 700, 500))
  square.save("AI深度学堂_分享小图_500x500.png")
  ```
